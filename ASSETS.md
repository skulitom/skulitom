# Project previews

The profile combines original animated illustrations with previews from Artem's own project repositories. Anode uses an explanatory architecture diagram; Haltere and Primordia show actual recordings or simulation output.

- `assets/projects/haltere-liftoff-race.png`: a frame at 15 seconds from Haltere’s latest [Liftoff lap-following recording](https://github.com/skulitom/haltere/blob/main/docs/liftoff_race.mp4), extracted without cropping or visual changes. Shows live neural activity and the actual game view. MIT notice: `HALTERE-LICENSE.txt`. The older training-simulator image remains available for previously cached pages.
- `assets/projects/primordia.webp`: the existing portfolio poster for the actual Primordia simulation reel. MIT notice: `PRIMORDIA-LICENSE.txt`.
- `assets/projects/cathode.webp`: the existing portfolio copy of the Cathode application screenshot. MIT notice: `CATHODE-LICENSE.txt`.
- `assets/projects/litharness.webp`: the existing portfolio copy of LitHarness project artwork, not a UI screenshot. MIT notice: `LITHARNESS-LICENSE.txt`.
- `assets/projects/anode.svg` and `agentui.svg`: explanatory diagrams based on the respective public READMEs.

The restored header, LitHarness, AgentUI, Cathode, Android app banners, and footer use the original animated illustrations in `assets/v2/`, including their mobile variants. These are decorative illustrations, not application screenshots. Animations respect reduced-motion preferences. Static previews remain available for the portfolio and previously cached pages.

The restored toolkit pills in `assets/toolkit/v1/` use local Simple Icons 16.30.0 brand marks plus original terminal and database symbols. Icon source data and the CC0 license are included in `assets/toolkit/`.
